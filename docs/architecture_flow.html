Data Flow

Outbound Call Flow

Primary use case — how a call is dispatched, dialled, and managed end-to-end.

1
make_call.py
Creates LiveKit room via API.
Dispatches agent with metadata:
{phone_number, patient_id}
2
LiveKit Cloud
Assigns job to running agent.py worker.
3
agent.py — Entrypoint
Parses job metadata → phone_number + patient_id
load_patient_context() → injects into system prompt
Connects to LiveKit room
Dials via ctx.api.sip.create_sip_participant()
LiveKit SIP Bridge → Twilio → PSTN → Patient
Creates pipeline: VAD + STT + LLM + TTS
Starts AgentSession + BackgroundAudioPlayer
Speaks initial greeting via session.say()
4
Real-time Conversation Loop
Patient speaks → Silero VAD
Audio → STT → text transcript
Transcript → LLM → response (streaming)
Response → TTS → audio → patient hears
Thinking gap: typing sound ♪
5
Call Ends
participant_disconnected event fires
save_call_notes() → appends transcript to patient JSON
Session closes

⚡ Inbound Call (WebRTC)

Patient opens LiveKit Playground in browser → LiveKit auto-dispatches agent (agent_name="patient-support-agent") → same pipeline as outbound, minus the SIP dialling step.

🛡️ Interruption Handling

  • • 1.5 s min duration — ignores coughs, "hmm"
  • • 3+ words required to count as interruption
  • • False interruption → agent resumes from where it left off

Latency Reduction

Three layers work together to minimise perceived response time.

LayerWhereLatency Saved
Background typing sound BackgroundAudioPlayer ~0 ms — fills silence immediately
Filler phrases Prompt: "always start with 'I see...'" ~100 ms first tokens, ~300 ms TTS

Patient Data

Data Lifecycle

tools/patient_data.py handles loading context before and saving transcripts after each call.

📥 Pre-call: load_patient_context()

Reads patient JSON and formats it for the system prompt. Includes: name, medications, conditions, allergies, provider, and last 3 call summaries.

📤 Post-call: save_call_notes()

Extracts conversation transcript from session.history and appends it to the patient's call_history array.

  "name": "Sarah Johnson",
